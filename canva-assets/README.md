## 🌿 Curated High-Res Assets Breakdown

### 1. `curated_high_res/envelope/` (36 files)
- Envelope liners and texture backgrounds (up to 2400x1792)
- Wax seal stamps and monograms (SVGs and high-res PNGs)
- Postage stamp illustrations
- Front and back envelope flaps
- Botanical floral accents and leafy sprays

### 2. `curated_high_res/details/` (18 files)
- Event schedule cards and venue illustrations
- Direction / map pin markers
- Dress code and registry decorative badges

### 3. `curated_high_res/love_story/` (5 files)
- Polaroid and photo frame masks
- Milestone date and relationship timeline graphics

### 4. `curated_high_res/click_to_open/` (5 files)
- Wax seal button and click prompt illustrations
- Initial closed envelope graphic

### 5. `curated_high_res/shared_elements/` (23 files)
- Border foliage, eucalyptus, and sage botanical artwork
- Gold foil and paper texture overlays

## 🔤 Font Families

- **Arimo**: Sans-serif supporting Bold, Italics, Bold-Italics, Regular (OTF, WOFF, WOFF2)
- **Canva Sans**: Clean UI font (OTF, WOFF, WOFF2)
- **New Icon Script**: Elegant calligraphy script font for headings and monograms (OTF, WOFF, WOFF2)
- **Nanum Myeongjo**: Classic serif typography (TTF)
